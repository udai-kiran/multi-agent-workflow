Multi-Agent Workflow

Plan → Implement → Verify → Document → Review. Every pass, no skipping.

The Task Contract's risk level (TRIVIAL → HIGH_RISK) decides which plan and diff reviewers run. The agent that wrote a change never verifies or reviews it.

Hard Rules

🎯

Delegate the running, not the judgement

Workers implement. You decide the diagnosis, design, and verdict.

🔬

Verify is always independent

The agent that wrote the code never verifies or reviews it. Codex checks agy's work and vice versa; run-gates always runs.

📋

Literal output only

Tests pass = literal output you read. "All tests pass" with no output is not evidence.

🔪

Surgical changes

Touch only what the task requires. No speculative refactors or "improvements".

📦

Modular briefs

One file / one bounded change per brief. Independent briefs run in parallel.

🚫

Never git add -A

Name every file to stage. Never glob-add. Private artifacts must not be committed.

🔭

Two review rounds, max

Reviewers see the finished, documented diff. If round 2 finds fix-induced defects, contrarian challenges the diagnosis and you re-plan with the user.

⚡

Simplicity first

Minimum code that solves the problem. No features beyond what was asked.

Personas

Domain guidance passed to codex-worker as its third argument, or to agy-worker for fallback work. They live in .claude/personas/, so Claude Code does not register them as subagents. The coordinator also folds their quality rules into review prompts.
